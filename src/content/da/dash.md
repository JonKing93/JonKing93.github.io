DASH is a MATLAB package that facilitates paleoclimate data assimilation workflows. It includes frameworks to design and build state vectors, estimate proxy values using proxy system models (PSMs), and implement Kalman filters, particle filters, and optimal sensors. If has been used to implement a number of recent scientific studies, including:

* [Trends and variability in the Southern Annular Mode over the Common Era](sam)
* [Globally resolved surface temperatures since the Last Glacial Maximum](lgm)
* [Glacial cooling and climate sensitivity revisited](https://doi.org/10.1038/s41586-020-2617-x)
* [Pliocene warmth and patterns of climate change inferred from paleoclimate data assimilation](https://doi.org/10.1029/2024AV001356)
