The pfdf package is a numerical Python library designed to facilitate postfire debris-flow hazard assessments and research. The library provides routines to:

* Analyze watersheds
* Delineate and characterize stream segment networks
* Download commonly used datasets
* Implement hazard assessment models
  * Debris flow likelihood
  * Potential sediment volume
  * Triggering rainfall thresholds
  * Combined hazard classifications
* Export results to standard GIS formats

Pfdf is the core engine used to produce the [PWFDF collection](https://www.sciencebase.gov/catalog/item/6818f950d4be0208bc3e0165), the USGS's postfire debris-flow hazard assessment product.
